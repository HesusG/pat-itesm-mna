# Plan de Acción Tutorial — PLN (MNA)

Tablero del **Plan de Acción Tutorial** para la materia de *Procesamiento de Lenguaje Natural*
de la Maestría en Inteligencia Artificial Aplicada (MNA) del Tecnológico de Monterrey.

🔗 **Sitio:** https://hesusg.github.io/pat-itesm-mna/

El sitio presenta:

- **El plan por objetivos (OKR)** con el NPS de la materia como métrica norte.
- **Indicadores de *learning analytics*** a partir de métricas de Canvas y Zoom.
- **Seguimiento por semáforo** (verde / amarillo / rojo) para detectar a tiempo a quien necesita apoyo.

> Los datos del tablero son **de muestra** (ficticios) para ilustrar el método; no son mediciones reales.

Estética neobrutalista. Hecho como actividad del curso *Temas Selectos de Educación* (UPAEP).
